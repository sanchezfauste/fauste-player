# Teklatua

| Tekla lehenetsia | Ekintza |
|---|---|
| `1` … `9` | Play 1–9 erreproduzitzaileetan (beren Play botoiaren berdina) |
| `F1` … `F12` | Jaurti erakutsitako kartutxo-orriko 1–12 kartutxoak |
| `Ctrl+Space` | Gelditu kartutxo guztiak, eta kartutxoen CUEa (kartutxo-panelaren **Gelditu dena** botoia) |
| `Delete` / `Backspace` | Kendu hautatutako pista erakutsitako zerrendatik (ez airean dagoen bitartean) |
| `Esc` | Itxi menuak eta Ezarpenak; utzi "Audioa airean dago" elkarrizketa-koadroa; garbitu hautapena |

- Tekla bati eusteak ez du errepikatzen: `1` teklari eutsiz gero, Play behin
  sakatzen da.
- Laster-tekla batek bere laster-bidea bakarrik egiten du: botoi batek
  teklatuaren fokua badu, laster-bide bati esleitutako `Space` edo `Enter`
  teklek ez dute botoi hori ere sakatzen, eta `Tab` teklako edo gezi bateko
  laster-bide batek ez du fokua mugitzen.
- Laster-teklei ez zaie jaramonik egiten testu-eremu batean idazten ari
  zaren bitartean, zerrenda baten izenean, adibidez.
- Botoia ilunduta duen laster-tekla batek ez du ezer egiten (adibidez,
  Gelditu geldituta dagoen erreproduzitzaile batean). Salbuespen bakarra
  kartutxo guztiak gelditzeko laster-tekla da, kartutxoen CUEa ere
  gelditzen baitu.

## Laster-teklak aldatzea {#changing-shortcuts}

![Ezarpenak, Laster-teklak: ekintza bakoitza bere teklarekin](../../images/guide/settings-shortcuts.png)

**Ezarpenak → Laster-teklak** atalean, egin klik ekintza batean eta sakatu
tekla (Ctrl, Alt, Shift edo Cmd teklekin, nahi baduzu). Beste ekintza batek
tekla hori erabiltzen badu jada, haren izena erakusten da. Aukeratu
**Esleitu** tekla mugitzeko, edo **Utzi**. **Kendu** botoiak laster-tekla
bat kentzen du, eta **Leheneratu balio lehenetsiak** botoiak (atalaren
goiko eskuinaldean) goiko taula leheneratzen du. Erabilgarri dauden
ekintzak, erreproduzitzaile eta kartutxo guztietarako:

- play, aurrekoa, berrabiarazi, pausatu, gelditu, itzaltzearekin gelditu
  eta CUE erreproduzitzaile batean (aurrekoak eta berrabiarazik ez dute
  tekla lehenetsirik);
- jaurti erakutsitako orriko kartutxo bat;
- gelditu kartutxo guztiak (kartutxo-panelaren **Gelditu dena**);
- erakutsi edo ezkutatu kartutxo-panela;
- hurrengo edo aurreko kartutxo-orria.

`Delete`, `Backspace` eta `Esc` ezin dira aldatu.
