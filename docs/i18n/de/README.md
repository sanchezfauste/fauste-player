# Fauste Player — Benutzerhandbuch

<div class="ai-notice" role="note">Dieses Handbuch wurde mit KI aus dem englischen Handbuch übersetzt (v0.13.1-15-gfcd6eac6, Commit fcd6eac) und kann Fehler enthalten. Bei Abweichungen gilt die englische Fassung. <a href="../index.html" hreflang="en">Das englische Original lesen</a></div>

Fauste Player ist eine Playout-Anwendung für Radiostudios. Sie betreibt
mehrere unabhängige **Player** nebeneinander. Jeder Player hat seine eigenen
Playlists und sein eigenes Transportfeld. Die Player können Tracks mit
überlappenden Mixen verketten, auf einem separaten **CUE**-Ausgang vorhören
und Abstürze überstehen, ohne von sich aus etwas auf Sendung zu bringen.

Die Oberfläche gibt es auf Englisch, Spanisch, Katalanisch, Niederländisch,
Französisch, Galicisch, Deutsch, Italienisch, Baskisch, Polnisch und
Portugiesisch. Sie folgt der Sprache des Betriebssystems, sofern du in den
Einstellungen keine andere wählst. Die Oberfläche in allen Sprachen, auch
Englisch und Spanisch, wurde mit KI erstellt und kann Fehler enthalten.
Korrekturen sind als Issues oder Pull Requests willkommen.

Das Handbuch gibt es auch in weiteren Sprachen, mit KI aus dem
englischen Handbuch übersetzt: Wähle im [Online-Handbuch](https://sanchezfauste.com/fauste-player/guide/)
eine mit dem Globus-Button in der oberen Leiste.
Eine übersetzte Seite weist oben darauf hin und verlinkt auf die
englische Seite, die maßgeblich ist, wenn beide voneinander abweichen.
