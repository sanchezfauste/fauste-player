# Tastatur

| Standardtaste | Aktion |
|---|---|
| `1` … `9` | Play auf den Playern 1–9 (wie ihr Play-Button) |
| `F1` … `F12` | Carts 1–12 der angezeigten Cart-Seite starten |
| `Ctrl+Space` | Jedes Cart und das Cart-CUE stoppen (der Button **Alle stoppen** der Cartwall) |
| `Delete` / `Backspace` | Den ausgewählten Track aus der angezeigten Playlist entfernen (nicht, solange er on Air ist) |
| `Esc` | Menüs und Einstellungen schließen; den Dialog „Audio ist on Air“ abbrechen; die Auswahl aufheben |

- Eine gehaltene Taste wiederholt sich nicht: Eine gehaltene `1` drückt Play
  nur einmal.
- Eine Shortcut-Taste löst nur ihr Kürzel aus: Hat ein Button den
  Tastaturfokus, drückt eine auf ein Kürzel gelegte `Space`- oder
  `Enter`-Taste nicht zusätzlich diesen Button, und ein Kürzel auf `Tab` oder
  einer Pfeiltaste verschiebt den Fokus nicht.
- Kürzel werden ignoriert, während du in ein Textfeld tippst, etwa einen
  Playlist-Namen.
- Ein Kürzel, dessen Button abgeblendet ist, bewirkt nichts (zum Beispiel
  Stopp bei einem gestoppten Player). Die einzige Ausnahme ist das Kürzel zum
  Stoppen aller Carts, das auch das Cart-CUE stoppt.

## Kürzel ändern {#changing-shortcuts}

![Einstellungen, Tastenkürzel: jede Aktion mit ihrer Taste](../../images/guide/settings-shortcuts.png)

Klicke unter **Einstellungen → Tastenkürzel** auf eine Aktion und drücke die
Taste (gern mit Ctrl, Alt, Shift oder Cmd). Wird diese Taste bereits von einer
anderen Aktion verwendet, wird deren Name angezeigt. Wähle **Zuweisen**, um die
Taste zu verschieben, oder **Abbrechen**. **Entfernen** löscht ein Kürzel, und
**Standardwerte wiederherstellen** (oben rechts im Abschnitt) stellt die
obige Tabelle wieder her. Verfügbare Aktionen, für jeden Player und jedes Cart:

- Play, Zurück, Neustart, Pause, Stopp, Ausblenden und CUE an einem Player
  (Zurück und Neustart haben keine Standardtaste);
- ein Cart der angezeigten Seite starten;
- jedes Cart stoppen (**Alle stoppen** der Cartwall);
- die Cartwall ein- oder ausblenden;
- nächste oder vorherige Cart-Seite.

`Delete`, `Backspace` und `Esc` lassen sich nicht ändern.
