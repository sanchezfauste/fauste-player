# Fauste Player — User guide

Fauste Player is a playout application for radio studios. It runs several
independent **players** side by side. Each player has its own playlists and
transport. Players can chain tracks with overlapping mixes, pre-listen on a
separate **CUE** output and survive crashes without putting anything on air
by themselves.
